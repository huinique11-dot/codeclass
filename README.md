# 코드교실 (codeclass)

학생이 **참여코드로 입장 → 개인코드 발급 → 다음 시간에 개인코드로 다시 입장**해서
단계별 수업을 따라 하는 사이트예요. Cloudflare Workers와 D1으로 돌아가요.

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 학생 입장 | `/` | 참여코드로 처음 입장(개인코드 발급), 개인코드로 다시 입장 |
| 학생 수업 | `/class` | 단계별 안내, '이 단계를 해봤어요' 체크, 선생님께 도움 요청 |
| 선생님 공간 | `/teacher` | 수업 만들기(참여코드 발급), 학생 진도·도움 요청 보기, 안내 단계 바꾸기, 개인코드 재발급 |

## Cloudflare에 발행하기

### 1. GitHub 저장소 연결

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인해요.
2. **Workers 및 Pages** → **애플리케이션 생성** → **Import a repository**(저장소 가져오기)를 눌러요.
3. GitHub 계정을 연결하고 `codeclass` 저장소를 골라요.
4. 설정은 기본값 그대로 두면 돼요.
   - 빌드 명령: 비워 두기
   - 배포 명령: `npx wrangler deploy`
5. **배포**를 눌러요.

입장 기록을 저장할 D1 데이터베이스(`codeclass-db`)는 처음 배포할 때 **자동으로 만들어져요**.
표(테이블)도 사이트가 처음 열릴 때 자동으로 만들어지니, 따로 할 일은 없어요.

> 배포 기록에 D1 관련 오류가 나오면 이렇게 해 주세요.
> 1. **저장소 및 데이터베이스 → D1**에서 `codeclass-db`라는 이름으로 데이터베이스를 직접 만들어요.
> 2. 그 데이터베이스의 ID를 `wrangler.jsonc`의 `d1_databases` 안에 `"database_id": "복사한 ID"`로 넣어요.

### 2. 선생님 비밀번호 정하기

1. 방금 만든 Worker → **설정** → **변수 및 비밀(Variables and Secrets)** → **추가**를 눌러요.
2. 유형은 **비밀(Secret)**, 이름은 `TEACHER_PASSWORD`, 값은 원하는 비밀번호로 정해요.
3. 저장(배포)해요.

비밀번호를 설정하기 전에는 선생님 공간에 들어갈 수 없어요.

### 3. 수업 열기

1. `https://codeclass.<내 하위도메인>.workers.dev/teacher`에 들어가 비밀번호를 입력해요.
2. 수업 이름을 적고 **수업 만들기**를 누르면 6자리 참여코드가 나와요.
3. 학생에게 참여코드나 **입장 링크**를 알려 주세요. 링크로 들어오면 참여코드가 자동으로 채워져요.

## 수업 내용 바꾸기

학생 화면의 단계 내용은 **`public/steps.js` 한 파일**에 있어요.
제목, 설명, 할 일 목록, 도움말, 링크를 고치고 GitHub에 저장하면 Cloudflare가 자동으로 다시 발행해요.

- 사이트 이름(`코드교실`)도 같은 파일 맨 위 `CLASS_INFO`에서 바꿀 수 있어요.
- '해봤어요' 기록은 **단계 번호**로 저장돼요. 수업 중에는 단계를 중간에 끼워 넣지 말고 맨 뒤에 추가하세요.

## 알아 두면 좋은 점

- **개인코드**는 `ABCD-EFGH` 모양의 8자리예요. 학생이 잃어버리면 선생님 공간에서 **개인코드 재발급**을 누르세요. 그러면 예전 코드는 더 이상 쓸 수 없어요.
- **화면 새로고침:** 학생 화면과 선생님 화면은 5초마다 새 정보를 불러와요.
- **단계 안 할 일 체크:** 각 단계 안의 작은 체크(할 일 목록)는 그 기기에만 저장돼요. 선생님 화면에 보이는 진도는 '이 단계를 해봤어요' 기준이에요.
- **입장 닫기:** 선생님 공간의 **입장 닫기**를 누르면 새 학생이 들어올 수 없어요. 이미 개인코드가 있는 학생은 다시 입장할 수 있어요.

## 미리보기 (입장 없이 화면 보기)

디자인을 고칠 때는 주소 끝에 `?preview`를 붙이면 입장 없이 예시 데이터로 화면을 볼 수 있어요.
서버에는 아무것도 저장되지 않아요.

- 학생 수업 화면: `/class?preview`
- 선생님 공간: `/teacher?preview` (비밀번호 없이 예시 학생 6명)

## 내 컴퓨터에서 실행해 보기 (선택)

```bash
npm install
```

```bash
echo "TEACHER_PASSWORD=test1234" > .dev.vars
```

```bash
npm run dev
```

실행한 뒤 `http://localhost:8787`을 열면 돼요. 내 컴퓨터에서 연 사이트는 기록도 내 컴퓨터에만 저장돼요.

## 파일 구성

```
src/worker.js      서버: 입장·개인코드·진도 저장 (D1)
public/index.html  학생 입장 화면
public/class.html  학생 수업 화면
public/teacher.html 선생님 공간
public/steps.js    ✏️ 수업 단계 내용
public/style.css   디자인
public/common.js   화면들이 함께 쓰는 도구
public/preview.js  ?preview 미리보기용 예시 데이터
wrangler.jsonc     Cloudflare 설정
```
